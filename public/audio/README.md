# Audio Directory

This directory is for background music.

## How to Use

1. **Add Your Music**: Place your audio file here
2. **File Name**: Name it `background-music.mp3` (or update the reference in MusicPlayer component)
3. **Supported Formats**: MP3, WAV, OGG
4. **File Size**: Keep under 5MB for best performance
5. **Rights**: Ensure you have permission to use the music

## Recommended Music

Choose a song that:
- Is meaningful to both of you
- Has a romantic or emotional tone
- Isn't too energetic (calm background music works best)
- Is appropriate length (2-5 minutes, looping)

## Music Sources

- **Personal Library**: Use a song you both love
- **Royalty-Free Music**: 
  - [Incompetech](https://incompetech.com/)
  - [Bensound](https://www.bensound.com/)
  - [YouTube Audio Library](https://www.youtube.com/audiolibrary/)

## Example

```
public/audio/
└── background-music.mp3
```

If the music file is missing, the music player button won't be displayed (no errors).
